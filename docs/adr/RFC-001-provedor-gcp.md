# RFC-001: Provedor de Cloud (GCP)
## Contexto
O projeto demanda uma nuvem publica para hospedar K8s, BD e Serverless.
## Decisão
Foi escolhido o Google Cloud Platform (GCP) utilizando o GKE, Cloud Run Functions v2 e Cloud SQL devido a familiaridade técnica e melhor tier gratuito/promocional, mitigando altos custos para o Tech Challenge.
